# 거짓말쟁이를 찾아라! 🥔 — 모바일 멀티플레이 웹앱

6개 조가 **각자 다른 제시어**로 5판을 진행하는 한국어 말하기 수업용 프로그램입니다.

## 구현 내용

- 한 주소로 접속해 1~6조 입장 (1~5조 각 5명, 6조 6명)
- 조의 첫 번째 입장자가 조장. 조장만 시작/판 종료/라운드 초기화 가능
- 조마다 한 판에 시민 N-1명과 라이어 1명 **서버에서 무작위 배정**
- 독립적으로 감자 🥔 1명 **서버에서 무작위 배정** (라이어도 감자가 될 수 있음)
- 시민만 제시어가 보이고 라이어에게는 ??? 표시
- 역할 카드 가리기/다시 보기, 새로고침해도 동일한 역할 유지
- 조별 5판, 총 30개의 겹치지 않는 제시어 사전 등록
- 작은 한국어 지시문 + 태국어 안내문
- 제시어와 다른 사람의 역할은 서버 응답으로 노출되지 않음
- 조별 독립 속도로 진행, 결석자 발생 시 **3명 이상이면 시작 가능**

## 모바일에서 사용하기 — 실제로 여러 기기가 동시에 접속하려면

**이 ZIP은 완성된 서버 소스 코드이지, 공개 웹주소가 아닙니다.** 인터넷으로 호스팅해야 교실에서 접속할 수 있습니다. 추천 절차:

1. 압축을 풀고 파일을 GitHub 저장소에 업로드합니다 (`package.json`, `server.js`, `public/index.html`, `render.yaml`).
2. Render (https://render.com/)에 로그인한 후 **New → Web Service**로 GitHub 저장소를 연결합니다.
3. Node 서비스로 생성하고 Build Command에 `npm install`, Start Command에 `npm start`를 설정합니다. 또는 저장소의 `render.yaml`을 Blueprint로 사용합니다.
4. Render가 제공하는 HTTPS 웹 주소를 휴대전화에서 열어 확인합니다. QR 코드는 그 주소로 직접 만들면 됩니다.
5. **실사용 전에 반드시** 서로 다른 휴대전화 5~6개로 같은 조에 들어가 다른 역할이 보이는지 확인해 주세요.

### 로컬 PC에서 먼저 테스트

Node.js 18 이상 설치 후 이 폴더에서:

```bash
npm start
```

PC에서는 `http://localhost:3000`을 열어 테스트할 수 있습니다. 같은 와이파이의 휴대전화에서는 PC의 LAN IP와 포트(`http://192.168.x.x:3000`)로 접속할 수 있습니다. PC 방화벽 및 네트워크 설정에 따라 연결이 제한될 수 있습니다.

### 사용법

- 각 학생이 **자기 휴대전화**로 접속 → 조 선택 → 이름 입력 → 입장
- 조원이 다 들어오면 첫 번째 입장 학생(조장)이 판 시작
- 자기 카드 확인 후 숨김 → 1차 힌트 → 1차 의심 → 2차 힌트 → 2차 의심 → 투표 → 라이어 정답 도전
- 판 종료 후 조장이 다음 판 시작

### 중요한 운영 제약

- 서버 데이터를 로컬 `.game-state.json`에 기록하므로, **영구 디스크 없는 무료 클라우드 서버는 재배포·재시작 시 데이터가 초기화될 수 있습니다.** 수업 전 새 세션으로 시작하고, 실제 수업 도중 서버를 재배포하지 마세요.
- 같은 브라우저에서는 `localStorage`에 역할 토큰을 보존합니다. 사파리 개인 정보 보호 모드나 브라우저 데이터 삭제 시 토큰을 잃을 수 있습니다.
- 첫 학생이 조장이므로 **조장으로 쓸 학생을 먼저 입장**시키는 게 좋습니다.
- 다른 학생이 남의 휴대전화에 직접 접근하거나 화면을 찍으면 비밀을 보호할 수 없습니다.
- `ADMIN_PIN` 환경변수를 설정할 경우, 교사 전체 초기화 API를 별도로 사용할 수 있으나 UI는 제공하지 않았습니다.
- 원래 설계한 31명보다 출석이 적다면 6개 조에 분산할 수 있습니다. 각 조 정원은 고정이고 최소 3명이어야 시작합니다.
